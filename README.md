# 冒険者ギルド経営シミュレーション

## 🎯 ゲームの目的・コンセプト

プレイヤーは**冒険者ギルドの運営者**として、ギルドの経営を行う**経営シミュレーションゲーム**。

### プレイヤーの役割
- 冒険者ギルドを運営し、黒字経営を目指す
- 冒険者をダンジョンなどに派遣し、戦利品や報酬を獲得する
- 買い取った素材や魔物部位を市場に売却して利益を得る
- 固定経費（税金・人件費・光熱費）をやりくりしながら経営を維持する

---

## 💰 ゲームシステム概要

### 収入構造（収益源）
| 種別 | 説明 |
|------|------|
| 仲介手数料 | 冒険者のクエスト報酬からギルドが受け取る手数料（現在15%） |
| 戦利品の売却益 | 冒険者から買い取ったアイテム（魔物部位・鉱石・薬草等）を市場へ売却した差額利益 |

### 支出構造（ランニングコスト）
| 種別 | 説明 | 現在の日額 |
|------|------|-----------|
| 固定資産税 | ギルド施設にかかる税金（日換算） | 150 G/日 |
| 光熱費 | ギルド施設の光熱・水道代 | 80 G/日 |
| 人件費 | ギルド職員（受付・鑑定士・警備等）の給与 | 400 G/日 |
| **合計** | | **630 G/日** |

## 🔄 現在のゲームサイクル

1. **「📋 受付・クエスト派遣」** で待機中の冒険者をクエストへ派遣
2. **「▶ 1日進める」** で時間を進行
   - 固定経費（人件費・税金・光熱費）が自動引き落とし
   - 派遣中クエストの残日数が減少
   - クエスト完了時 → 仲介手数料獲得＋戦利品が倉庫に追加
3. **「📦 倉庫・戦利品売買」** で戦利品を市場に売却し利益を確保
4. **「📊 収支台帳」** で黒字/赤字の確認

## 📐 開発方針・アーキテクチャ合意

本プロジェクトの開発指針・AIエージェント向け規約は [AGENTS.md](AGENTS.md) に記録されています。
* **サーバー非依存**: 完全ローカル・オフライン完結
* **コア分離**: ゲームロジック（`core`）は egui 非依存にし、テスト可能にする
* **データ永続化**: `serde` ベースのファイル保存（まずは JSON、将来的なローカル暗号化にも対応）
